Criador Shorts

O Criador Shorts é uma ferramenta de linha de comando, de uso pessoal, que publica vídeos curtos verticais (YouTube Shorts) no canal do próprio autor, Juliano Ferreira, usando os Serviços de API do YouTube.

Este app usa os Serviços de API do YouTube. Leia a Política de Privacidade, os Termos de Serviço e os Termos de Serviço do YouTube.

O que a ferramenta faz

  • Envia para o canal do autor os vídeos que ele mesmo produziu, com título, descrição, tags e data de publicação.
  • Marca como conteúdo sintético os vídeos gerados ou alterados com inteligência artificial.
  • Usa apenas o escopo youtube.upload. Não lê dados de outros canais, de espectadores nem comentários.

Quem usa

Somente o dono do canal, no próprio computador. A ferramenta não é oferecida ao público, não tem cadastro de usuários e não roda em servidor.

Criador Shorts (English)

Criador Shorts is a personal command-line tool that publishes short vertical videos (YouTube Shorts) to its author's own YouTube channel, using the YouTube API Services.

What it does

  • Uploads videos produced by the author to the author's channel, with title, description, tags and publish date.
  • Discloses videos generated or altered with AI as synthetic content.
  • Requests only the youtube.upload scope. It does not read data from other channels, viewers or comments.

Who uses it

Only the channel owner, on his own computer. The tool is not offered to the public, has no user sign-up and does not run on a server.
